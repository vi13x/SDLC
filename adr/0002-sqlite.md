# ADR-0002 Локальное хранение в SQLite

## Контекст и постановка задачи

История должна переживать перезапуск и сохраняться транзакционно.

## Драйверы решения

Обязательные функции SRS, локальная работа, проверяемость, срок 11.12.2026 и учебный бюджет до 4 400 BYN.

## Рассмотренные варианты

SQLite; JSON-файлы; PostgreSQL.

## Итог решения

SQLite даёт транзакции и индексы без установки отдельного сервера.

### Последствия

SQLite соответствует одному локальному пользователю; JSON требует собственной логики целостности; PostgreSQL удобен для сети, но избыточен для MVP.

### Подтверждение

Проверить откат операции, внешние ключи, копию и восстановление. Проверка реализации пока не проводилась.

## Плюсы и минусы вариантов

SQLite соответствует одному локальному пользователю; JSON требует собственной логики целостности; PostgreSQL удобен для сети, но избыточен для MVP.
